# Análisis de requisitos

## Objetivo

Diseñar una infraestructura informática para una PYME que permita alojar una página web corporativa y un sistema de gestión interna.

## Requisitos funcionales

- Servidor web Apache.
- PHP para aplicaciones web.
- Base de datos MySQL.
- Acceso remoto mediante SSH.
- Sistema de monitorización.
- Sistema de copias de seguridad.

## Requisitos no funcionales

- Seguridad.
- Disponibilidad.
- Escalabilidad.
- Facilidad de mantenimiento.

## Usuarios

| Usuario | Función |
|----------|----------|
| Administrador | Gestión de sistemas |
| Empleado | Uso de aplicaciones internas |
| Cliente | Acceso a la web |
