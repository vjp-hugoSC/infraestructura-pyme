# Proyecto: Infraestructura LAMP para una PYME

## Autor

Hugo Serrano Calderón

## Descripción

Este proyecto documenta el diseño e implantación de una infraestructura LAMP para una pequeña empresa.

La infraestructura incluye:

- Ubuntu Server 22.04
- Apache
- PHP
- MySQL
- SSH seguro
- Firewall UFW
- Monitorización con Netdata
- Copias de seguridad automáticas
- Balanceador HAProxy
- Plan de recuperación ante desastres
